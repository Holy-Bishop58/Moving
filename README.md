# Moving
Overview

This Clarity smart contract provides a structured workflow for project creation, problem solving, and contract acquisition in Google Clarity Web3. Each project is defined with a problem, upgraded with a solution, and awarded a contract once solved, ensuring accountability and innovation.

Features

Create Project → Register a project with title and problem statement.

Solve Problem → Add a solution and update the project status to solved.

Obtain Contract → Approve solved projects to become contracted.

View Project → Retrieve full project details including owner, problem, and solution.

Why It Stands Out

The contract is short, unique, and error-free, combining project management and problem-solving into one transparent Web3 workflow, making it ideal for Google Clarity Web3 initiatives.
